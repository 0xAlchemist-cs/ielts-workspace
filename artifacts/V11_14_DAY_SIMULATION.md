# V11 14-Day Memory Simulation (extension)

Week 1 = the 7-day simulation. Week 2 adds:

| Day | Behaviour | Memory change |
|---|---|---|
| D8 | the D1 challenge items: 4th consecutive success each | **challenge disappears** (production misses cleared) — an early problem CAN retire (stale-memory requirement) |
| D9 | new recurring error (preposition, ×2 slips) | new challenge "Using prepositions accurately" replaces the retired one in the top slot |
| D10 | 3 successes on that error's correction | "A mistake that's fading — corrected three times in a row" appears under improvements |
| D11 | recognise ×7 correct / produce ×5 wrong on a fresh comparison set | **pattern**: "You recognise more than you can produce" (recognition ≥60%, production ≤40%, ≥5 each) |
| D12 | IELTS speaking session | speaking task selection biases to reason-type questions (memory→speaking, IELTS only) |
| D13 | long-gap checks: 2 items survive ≥7 days | "Remembering after many days — 2 expressions have survived long gaps" improvement |
| D14 | transfer: 2 expressions used in writing across modules | recently-strengthened notes switch to "Used in reading + writing" (contexts ≥2) |

Old problems disappear (D8), new ones emerge (D9), patterns accumulate only with counted evidence, and contradictory states render as nuance ("getting better, but still drops") rather than absolutes.
